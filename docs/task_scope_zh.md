# TALOS 桌面操作任务边界

## 最终目标

机器人在双脚保持原地接触、base 不发生明显平移或转动的条件下，从桌面主动接近物体，建立真实手指接触，夹持物体并将其移动到指定目标位姿。

## 策略拆分

1. **Grasp policy**：从绿色取物区抓住蓝色物体并稳定抬离桌面；
2. **Transport/place policy**：从 grasp policy 的成功状态开始，将物体移动并释放在红色目标区。

两个策略共享机器人、桌面、物体状态和动作定义，切换判据为右手至少两处接触且物体稳定抬升 8 cm。首版只实现和训练 grasp policy。

## 任务阶段

1. **Phase 0：模型与接口**
   - 验证 TALOS、桌面、自由物体和接触传感器；
   - 腿部保持默认站立控制，policy 控制上身和夹爪；
   - 双手到达桌面工作空间中的目标位姿。
2. **Phase 1：privileged-position 真实接触抓取**
   - 蓝色立方体或球体在绿色区域内随机初始化；
   - actor 和 critic 直接接收 robot root frame 下的物体中心真值；
   - 使用右手接近、至少两处接触和抬升奖励；
   - 双腿由 policy 控制，base 不固定，机器人必须自主保持平衡；
3. **Phase 2：视觉位置抓取**
   - actor 的三维物体中心输入改由视觉网络估计；
   - critic 可继续使用仿真真值作为 asymmetric privileged observation；
   - 夹持稳定性、滑移和碰撞惩罚；
4. **Phase 3：搬运与放置**
   - 随机目标位姿；
   - 奖励物体轨迹而非仅奖励手部轨迹；
   - 保持站立和平衡约束。
5. **Phase 4：泛化与 sim-to-real**
   - 随机质量、摩擦、尺寸、质心、传感器噪声和延迟；
   - 使用实机可得观测，critic 可使用受控 privileged information；
   - 在未见物体与负载上做 OOD 评估。

## Grasp v0 控制边界

- policy action：全部 `leg_*`、`torso_*`、`arm_*` 和右夹爪主关节；
- 固定目标控制：头部和左夹爪；
- base 保留浮动动力学，不焊接到世界，以便训练真正的站立稳定性；
- 手指被动关节继续通过 TALOS 真实机械耦合约束运动。

## Grasp v0 观测接口

- actor：关节位置、速度、上一动作、base 角速度、投影重力，以及物体中心真值；
- critic：actor 全部输入，外加 base 线速度；
- 物体中心项固定为 3 维，后续由视觉估计替换 actor 侧数据源；
- 后续加入实机可用的腕部 F/T 和接触历史。

## 第一版验证标准

- 所有实体能独立编译；
- 机器人具有 14 个手指关节、2 个夹爪执行器和 12 个耦合约束；
- 桌面为 fixed body，物体具有 6-DoF freejoint；
- 环境配置将腿、躯干、双臂和右夹爪暴露给 policy；
- 右手—物体、双脚—地面和非法身体接触传感器可解析；
- 立方体和球体任务都能 reset、step，且奖励与终止值有限。
